# 🧩 머지 비스트로: 유적의 비밀 (Merge Bistro: Mystery of the Ruins)

> **Merge-2 퍼즐 & 바닷마을 레스토랑 재건 스토리 게임**
> 폭풍우로 무너진 해변 비스트로를 재건하고, 실종된 사장님과 뒷산 고대 유적의 비밀을 풀어나가는 머지-2 게임입니다.

---

## 🌟 주요 게임 특징 및 아키텍처

1. **63타일 (7×9) 영구 머지 보드**
   - 중앙 3×3 오픈 타일에서 생성기를 탭하여 기본 재료(밀가루, 원두, 씨앗)를 스폰합니다.
   - 동일한 레벨의 아이템 2개를 합성하여 상위 요리로 진화시킵니다 (최대 Lv.11 시그니처 과일 타르트).
   - 아이템 합성 시 인접한 **거미줄(🕸️)** 및 **잠긴 상자(🔒)**가 연쇄 해금되어 보드가 점진적으로 확장됩니다.

2. **5대 주력 생산 체인 명세**
   - 🌾 **화덕 베이커리**: 밀가루 ➔ 반죽 ➔ 식빵 ➔ 바게트 ➔ 크루아상 ... ➔ 시그니처 과일 타르트 (Lv.11)
   - ☕ **바리스타 카페**: 원두 ➔ 에스프레소 ➔ 아메리카노 ➔ 카페라떼 ... ➔ 시그니처 구름 아인슈페너 (Lv.10)
   - 🦀 **항구 그릴 요리**: 비단조개 ➔ 대하 꼬치 ➔ 연어 스테이크 ... ➔ 황금 랍스터 플래터 (Lv.10)
   - 🌱 **비스트로 텃밭**: 새싹 ➔ 바질 ➔ 로즈마리 ➔ 애플민트 ... ➔ 골든 엘릭서 허브 (Lv.9)
   - 🔍 **유적 탐사 도구**: 돋보기 ➔ 솔 ➔ 나침반 ➔ 손전등 ➔ 열쇠 ➔ 사장님 일기장 ➔ 성간 해독기 (Lv.8)

3. **능동형 손님 주문 큐 (Active Orders Queue)**
   - 부엉이 촌장, 바리스타 고양이 밀로, 집배원 강아지 토비 등 매력적인 동물 주민들의 요리 주문.
   - 보드 내 재료 준비 시 초록빛 인디케이터 및 원클릭 서빙.
   - 서빙 시 **코인(🪙)**과 **별(⭐)** 획득.

4. **마을 & 식당 7단계 메타 복원 (Multi-Chapter Restoration)**
   - 1장: 오션 테라스 복구 (5⭐)
   - 2장: 메인 다이닝 홀 & 앤틱 테이블 (8⭐)
   - 3장: 참나무 화덕 메인 오븐 정비 (12⭐)
   - 4장: 에스프레소 바리스타 카운터 오픈 (16⭐)
   - 5장: 뒤뜰 유기농 온실 텃밭 개간 (20⭐)
   - 6장: 뒷산 유적 입구 가시 덩굴 제거 (25⭐)
   - 7장: 비밀 레시피 금고 & 별빛 제단 해독 (30⭐)
   - 각 챕터마다 **3가지 인테리어 디자인 스타일**을 직접 선택 가능!

5. **공식 쿡스타그램 (Cookstagram) & 직원 패시브**
   - 동물 직원들이 SNS에 올리는 비하인드 컷 및 팔로워 달성 보상.
   - 고양이 밀로(라떼아트 보너스), 강아지 토비(서빙 코인 +15%), 곰 브루노(화덕 쿨다운 단축) 등 고유 패시브 버프.

6. **Web Audio API 절차적 사운드 신시사이저**
   - 외부 오디오 파일 의존성 없는 가볍고 경쾌한 펜타토닉 음계 합성 사운드 (레벨별 피치 상승 팝음, 서빙 축하 아르페지오, 복원 팡파르).

7. **수리 경제 모델 시뮬레이터 & 안티그래비티 2.0 프롬프트 포털**
   - $D_L = 2^{L-1}$ 기하급수 수요 곡선 시뮬레이터 및 Chart.js 그래프 내장.
   - Google Antigravity 2.0 ROCK 프롬프트 A to Z 원클릭 복사기.

## 🛠️ 기술 스택

- **Frontend**: React 19, TypeScript, Vite 6
- **Styling**: Tailwind CSS (Warm Neutral Palette: Cream, Sage, Terracotta, Wood)
- **State Management**: Zustand 5 (LocalStorage 자동 저장 및 오프라인 에너지 회복 지원)
- **Audio**: Web Audio API Procedural Synthesizer
- **Visual FX**: Canvas Confetti, CSS Spring Animations
- **Charts**: Chart.js

## 🚀 로컬 실행 방법

```bash
cd merge-town
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속.

## 📦 프로덕션 빌드

```bash
npm run build
```
빌드된 파일은 `dist/` 디렉토리에 생성됩니다.

# Merge Town UI & Polish Protocol
1. 보드는 7x9 고정 63타일 그리드를 유지합니다.
2. 타일 상태(OPEN, COBWEB, LOCKED)는 시각적으로 명확하게 구분되어야 합니다.
3. 동일 아이템 합성 시 경쾌한 팝 애니메이션과 Web Audio 절차적 사운드(피치 상승)를 재생합니다.
4. 주문 충족 시 시각적 서빙 인디케이터(초록 체크/광채)와 코인/별 파티클 피드백을 제공합니다.
